## 题目描述

给定一张有 `n` 个城市、`m` 条双向航线的带权图。旅客需要从城市 `s` 到达城市 `t`，途中至多可以选择 `k` 条航线免费乘坐，求最少总花费。

## 输入格式

第一行输入 `n m k`，分别表示城市数、航线数和最多免费乘坐次数。

第二行输入 `s t`，表示起点和终点。

接下来 `m` 行，每行输入 `a b c`，表示城市 `a` 与 `b` 之间有一条票价为 `c` 的双向航线。

## 输出格式

输出从 `s` 到 `t` 的最少花费。

## 解题思路

把“已经使用了多少次免费机会”加入最短路状态。令 `dist[u][used]` 表示到达城市 `u`、恰好使用 `used` 次免费机会时的最小花费，其中 `0 <= used <= k`。

从状态 `(u, used)` 经过一条权值为 `w`、终点为 `v` 的航线时有两种选择：

1. 正常付费，转移到 `(v, used)`，新增花费 `w`；
2. 当 `used < k` 时免费乘坐，转移到 `(v, used + 1)`，新增花费 `0`。

这等价于在一个有 `k + 1` 层的分层图上求最短路。所有边权都非负，因此使用优先队列优化的 Dijkstra 算法。最终答案是 `dist[t][0..k]` 中的最小值。

## 正确性证明

任意一条合法旅行路线，都可以按照每条航线是否使用免费机会，唯一对应为分层图中的一条路径：付费时留在同一层，免费时进入下一层。该路径的权值恰好等于旅行的实际花费，并且层数不会超过 `k`。

反过来，分层图中从 `(s, 0)` 到任意 `(t, used)`（`used <= k`）的路径，也对应原图中的一条合法路线；跨层边代表免费乘坐，同层边代表正常付费，所以实际花费等于路径权值。

因此，合法方案与分层图中的目标路径保持相同花费。Dijkstra 能正确求出非负权分层图中的最短距离，取所有终点层的最小值便得到至多使用 `k` 次免费机会时的最小花费。

## 易错点与复盘

- 城市编号范围是 `0` 到 `n - 1`。
- 只有在 `used < k` 时才能转移到下一层，否则会越界并错误地使用更多免费机会。
- 答案要在终点的所有层中取最小值，因为免费机会不要求全部用完。
- 最短距离可能超过 `int` 范围，使用 `long long`。
- 优先队列需要按距离从小到大弹出状态。

## 复杂度

- 时间复杂度：`O((n k + m k) log(n k))`
- 空间复杂度：`O(n k + m)`

## 测试说明

- `sample1`：洛谷公开样例，一次免费机会应当用于降低最优路线的总费用。
- `sample2`：`k = 0`，退化为普通最短路。
- `sample3`：免费机会少于路径边数，并且不必全部边都付费。
